# 验收

## 构建

- 实际运行 XeLaTeX/Biber，退出码成功，辅助文件收敛。
- 不存在缺字、未定义引用/交叉引用、未执行 Biber、缺失资源或未处理的越界。
- 字体替代、模板默认字段、空参考文献和 Biber 警告必须解释；严格检查不能自动忽略。
- 保留 PDF 哈希和构建记录，后续改动需要重新生成与核对。

## 内容

- 根据输入建立结构清单，对照摘要、正文、公式、图表、脚注、引用与附录，无静默遗漏。
- 论文题名、姓名、学号、学院、导师和日期与用户资料一致；示例数据不能混入真实论文。
- 不把未识别公式转为空白，不把引用猜成文献，不把排版调整变成润色或新增研究结论。
- PDF 每页保留来源定位；DOCX 对照结构计数与特殊对象；TeX 检查依赖文件及宏。
- 数学密集 PDF 另核对所有公式编号、正文中的交叉引用与上下标；“文字层非空”不代表公式已恢复。章节目录要与原文结构清单一致，防止正文行首数字被误识别成标题。
- 可辅以中文字符序列、英文断词、表格数字与代码语法检查；这些不能替代版面检查。原页码与输出页码允许不同，但必须记录每个原页的内容去向。全文搜索 TODO、UNRESOLVED、替换字符和遗留提取占位符。

## 视觉

使用 `render` 输出所有页面并逐页打开。检查封面题名换行、字段下划线与底部空间；中文/英文摘要字号与行距；目录层级及页码；标题孤行；数学上下标、分式及编号；长表格跨页与图题位置；脚注和页眉页脚是否碰撞；参考文献悬挂缩进与长 URL。

每页应为 A4；封面无页码，摘要罗马数字，正文重新从 1 起。连续长文本与长摘要必须验证分页，不只检查短示例。`review/acceptance.json` 必须记录所审 PDF 哈希，避免把旧版审核用于新版。

## 测试范围

新模板至少验证一个包含多级标题、数学、图表、脚注、中文和英文文献的完整示例。导入流程至少验证 TeX 宏/相对资源、DOCX 公式/表格/图片/脚注、文本 PDF 和无文字扫描 PDF 的质量门槛。缺失输入依赖、修订、已有输出目录、缺失引用应给出明确失败或待核对状态，不伪报通过。

学校合规性与技术验证分开：即使全部技术检查通过，未取得对应学院规范时也仅标记“按 ruc-2021-local 历史配置完成”。
