## 规则与实现

下列“历史要求”均来自 L1 注释，尚未由原手册复核。“工程选择”不是学校要求。

| 项目 | 历史要求或采用值 | 实现 / 状态 |
|---|---|---|
| 纸张 | A4 纵向 | geometry，历史要求 |
| 页边距 | 上下 2 cm，右 1.5 cm，左 1.5 cm + 装订线 0.5 cm | 有效左边距 2 cm，历史要求 |
| 页眉 | 居中校标，4.13 × 0.98 cm | 使用用户提供 head.png；预留页眉高度与间距，工程调整 |
| 封面文头、题名 | 28 pt 黑体加粗居中 | 固定字号，允许换行；不用缩放掩盖超长题名 |
| 副题名 | 20 pt 黑体加粗，前置长划线 | 可选；元数据中不用重复写划线 |
| 封面信息 | 作者、学院、专业、年级、学号、导师、成绩、日期；20 pt，内容下划线 | 参数化；长字段换行并检查版面，成绩允许空白 |
| 论文编码 | 12 pt 黑体加粗，右对齐 | 显式字段，不根据学号猜测专业代码 |
| 中文摘要 | 标题 16 pt 黑体加粗；正文 12 pt 宋体，1.5 倍行距 | 修复旧实现的 small/字号继承问题 |
| 英文摘要 | 标题 16 pt TNR 加粗；正文 12 pt TNR，2 倍行距 | 显式设置字体字号和行距 |
| 关键词 | 12 pt；标签加粗；词间 3 格 | 使用可换行的 3 个中文字符宽度分隔；需据手册复核“格”含义 |
| 正文 | 12 pt 宋体，1.25 倍行距，首行缩进 2 汉字 | 使用 ctex 字体与段落设置 |
| 一级标题 | 三号黑体加粗居中；单倍行距；段前后各 1 行 | 16 pt；序号后 2 个汉字宽度 |
| 二级标题 | 四号黑体加粗左对齐 | 14 pt；其余同上 |
| 三级标题 | 小四号黑体加粗左对齐 | 12 pt；其余同上 |
| 四级标题 | 五号黑体加粗左对齐、单独占行 | 10.5 pt；paragraph 编号至 1.1.1.1 |
| 摘要页码 | I、II 等大写罗马数字 | 随页递增；长摘要不会硬编码重复页码 |
| 目录 | 内容目录；图表目录可选 | 不显示页码，沿用 L1/L2；层级至三级为工程选择 |
| 正文页码 | 从 1 开始，10.5 pt 宋体，居中“第1页” | 与旧代码的五号字号冲突时按注释 10.5 pt |
| 脚注 | 圆形标号，每页重新编号 | 以圆圈数字绘制，不受旧版 10 个符号上限影响 |
| 图表 | 三线表、表题在上、图题在下 | 保留旧模板习惯；编号连续为默认，可配置按章编号 |
| 参考文献 | L1 声称 GB/T 7714—2015 著者出版年制，但代码和 L2 为数字制 | 默认 numeric 保留样稿行为；author-year 显式可选，学院规范优先 |
| 附录、致谢 | 独立起页，进入目录 | 有内容才启用；附录支持 A、B 编号 |

TNR = Times New Roman。正式模式要求安装 SimSun、SimHei、KaiTi、FangSong、Times New Roman、Arial、Courier New；不随 skill 分发商业字体。`portable` 使用 Fandol/TeX Gyre，只供跨平台预览，报告明确列为字体替代，不能宣称严格合规。

## 已解决的旧模板差异

标题间距由统一命令控制；补齐四级标题；正文及摘要不再依赖字号继承；封面字段与排版分离；参考文献不再默认全库输出；不混用 mathptmx 与 fontspec；图表目录、附录和致谢按需启用。数学字体使用 TeX Gyre Termes Math，属于工程选择，不把 TNR 正文字体等同于数学字体。
